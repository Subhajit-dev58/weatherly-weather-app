# Weatherly 🌤

A simple and clean weather web app that shows real-time weather data using the OpenWeather API.

I built this project to practice working with APIs, async JavaScript, and building responsive UI.

🔗 Live App  
https://subhajit-dev58.github.io/weatherly-weather-app/

---

## Features

- Search weather by city name
- Get weather using your current location
- Dynamic background based on weather condition
- Loading state & error handling
- Clean glassmorphism UI
- Works on mobile and desktop

## Important Note about API Key 🔑

This project uses the OpenWeather API.

For security reasons, the API key is **not included** in this repository.

To run the project locally:

1. Get a free API key from  
   https://openweathermap.org/api

2. Open `script.js`

3. Replace this line:

```javascript
const apiKey = "YOUR_API_KEY_HERE";
```

with your own API key.

---

## Run Locally

Download the project and open `index.html` in your browser after adding your API key.
